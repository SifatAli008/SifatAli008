# Applying AI-WIP proposals

All AI-WIP Deploys commit to the shared branch **`aiwip/wip-review`**
(single PR: “AI-WIP: SEO / AEO / GEO / LLMEO review (WIP)”).
Proposal notes live under `docs/ai-wip-proposals/`.
When the **code_fix_agent** ran, Deploy also commits real Next.js source diffs
(SEO / AEO / GEO / LLMEO). Review those files in the PR before merge.

AI-WIP never pushes to `main` automatically — you merge the WIP review PR.
